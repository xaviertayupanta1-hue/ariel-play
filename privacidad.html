Política de privacidad

Última actualización: 12 de octubre de 2026

Esta política explica qué datos trata Ariel Play Dashboard (la «aplicación»), una herramienta interna de Ariel Play, y cómo los protege. La aplicación solo la utiliza el titular del canal de YouTube de Ariel Play para analizar su propio canal.

1. Servicios de la API de YouTube

La aplicación utiliza los servicios de la API de YouTube (YouTube Data API v3 y YouTube Analytics API). Al autorizarla, aceptas también las Condiciones del servicio de YouTube, y tus datos se rigen además por la Política de privacidad de Google.

2. Datos a los que accede

Solo con la autorización expresa del titular de la cuenta, mediante OAuth 2.0 y con permisos de solo lectura:

  • youtube.readonly: nombre, identificador y estadísticas públicas del canal (suscriptores, vistas, número de videos) y la lista de sus videos con sus estadísticas (vistas, me gusta, comentarios, duración, fecha de publicación).
  • yt-analytics.readonly: informes de YouTube Analytics del propio canal (vistas, tiempo de visualización, retención media, interacciones, suscriptores ganados y perdidos).
  • yt-analytics-monetary.readonly: ingresos estimados del propio canal según YouTube Analytics.

La aplicación no publica, modifica ni elimina contenido; no accede a mensajes, comentarios privados, datos de suscriptores individuales ni a ninguna otra información de la cuenta de Google.

3. Para qué se usan

Exclusivamente para mostrar al titular del canal un panel de gestión de su propio negocio audiovisual: rendimiento de cada video, evolución del canal y rentabilidad. Los datos no se venden, no se usan para publicidad, no se ceden ni se comparten con terceros y no se emplean para entrenar modelos de inteligencia artificial.

El uso y la transferencia de la información recibida de las API de Google cumple la Política de datos del usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

4. Dónde se guardan y cómo se protegen

  • Todos los datos se guardan únicamente en el equipo del titular, en una base de datos local. La aplicación no tiene servidores propios en internet.
  • La aplicación solo se comunica con los servidores de Google para obtener los datos autorizados.
  • Los tokens de acceso se almacenan cifrados; la clave de cifrado se guarda por separado y nunca se publica.

5. Conservación y eliminación

  • Los datos se conservan mientras el titular los necesite para su análisis histórico y puede borrarlos en cualquier momento.
  • El acceso puede revocarse en cualquier momento desde la propia aplicación («Desconectar») o desde la página de permisos de tu cuenta de Google. Tras la revocación, la aplicación deja de obtener datos nuevos y elimina sus tokens.
  • Para solicitar la eliminación de cualquier dato, escribe al contacto indicado abajo.

6. Cookies y este sitio web

Este sitio informativo no utiliza cookies ni herramientas de analítica. Está alojado en GitHub Pages, que puede registrar datos técnicos de acceso según la declaración de privacidad de GitHub.

7. Cambios

Cualquier cambio en esta política se publicará en esta página con su fecha de actualización.
